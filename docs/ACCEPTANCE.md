# 本地验收记录

## v0.4.2 手机导航与设置

Galaxy S24 通过无线 ADB 从 v0.4.1 同签名覆盖升级到 v0.4.2 Debug，保留原有 Hub 配置和用量数据。本轮在真机上用真实 Hub 验收手机 UI，取数未使用 ADB 反向转发。

| 验收项 | 结果 |
| --- | --- |
| S24 标题栏 | 五个主页面的标题左上位置和行高一致。滚动设置正文时，顶栏固定。 |
| S24 设置分组 | 核对总览、额度与余额、外观与图表等入口。进入卡片编辑后，返回键回到总览设置。 |
| S24 总览布局 | 使用真实 Hub 快照切换普通和紧凑。相同卡片的间距随选项变化。重开 App 后紧凑布局保留，切回普通后间距恢复。 |
| S24 检查更新 | 「关于」显示当前版本、GitHub 源码和鸣谢。发布前从 GitHub 查到当时最新公开稳定版 v0.4.1，并正确提示本机 v0.4.2 版本更高。 |
| 本地 CI 和发布包 | 25 项 Kotlin 单测、两端 Lint、Debug 和 Release 构建均通过。两端签名 Release APK 通过 Android 与 Wear OS 模拟器的同签名覆盖安装和启动检查。 |

### Galaxy S24 与 Galaxy Watch7 真机验收

两端通过无线 ADB，用与已安装版本证书相同的 v0.2.0 Debug APK 覆盖升级。Hub 配置和缓存均保留，两端通过 HTTPS 直接读取真实 Hub。

| 验收项 | 结果 |
| --- | --- |
| 时间范围和图表 | S24 总览和活动共用时间筛选，七种范围均完成切换。连续取数后，当日折线和 K 线均显示实测采样增量。 |
| 总览和额度排序 | 拖动保存后重启应用，卡片与账户次序均保留。验收后恢复原顺序。 |
| 断网缓存 | 使用 Android 防火墙做 App 级网络阻断，手机 Wi‑Fi 保持开启。重启 App 后，首页仅出现一条缓存提示，缓存用量仍可查看。解除阻断后成功获取新快照。 |
| 手表额度分组 | Watch7 使用自身 Wi‑Fi 独立直连。核对短时和周期窗口，同一工具在类别内以一个标题显示，并保留不同窗口。余额区暂无真实读数。 |
